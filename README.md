# Цикличный таймер HTML

Простой HTML-таймер для iframe

## Что делает

Отображает на экране крупную цифру с обратным отсчётом. При достижении нуля таймер автоматически сбрасывается и начинает отсчёт заново. Бесконечный цикл.

## Использование

### 1. Вставьте ссылку в iframe
```html
<iframe src="https://ukropik.github.io/timer.html?seconds=10" frameborder="0" width="100%" height="100%"></iframe>

Если не указывать ?seconds=, таймер работает по умолчанию на 10 секунд. 999max
Добавлен параметр hide если равен 1 или true таймер скрыт.
По умолчанию 0, показан.
